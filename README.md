# 🚀 Arpit Singh Patel — Modern Developer Portfolio

An ultra-responsive, high-performance portfolio website engineered with **HTML5**, **CSS3 (Custom Properties & Glassmorphism)**, and **Modern Vanilla JavaScript**.

Designed specifically for **Arpit Singh Patel** ([@Arpit-aka-appu](https://github.com/Arpit-aka-appu)), featuring his expertise in the **MERN Stack**, **Real-Time WebSockets**, **Python / AI**, and **Distributed Caching**.

---

## 🌟 Key Highlights & Features

- 🎨 **Modern Cyber-Clean & Glassmorphic UI**: Ambient particle background canvas, subtle neon gradients, and dark/light mode toggle with state persistence.
- ⚡ **Real-Time Architecture Showcase**: Interactive deep-dive modal detailing the system design for projects like **VibeCodeLive**, **Real-Time Messaging App**, and **Cache-Project**.
- 🔍 **Dynamic Filtering**: Instant category filtering for both **Technical Skills** and **Featured Projects**.
- 📊 **Live GitHub Integration**: Dynamically pulls live repository data and public stats from GitHub API (`@Arpit-aka-appu`).
- 📋 **1-Click Actions & Micro-Interactions**: Direct clipboard copy for email (`arpitsinghpatel9399@gmail.com`) with toast notification and interactive contact form.
- 📱 **100% Mobile & Accessibility Responsive**: Semantic HTML5, accessible ARIA attributes, and smooth responsive breakpoints.

## 💻 Quick Preview / Local Setup

You can run this portfolio locally with any static file server or by opening `index.html` in your browser:

### Option 1: Python Built-in Server
```bash
cd /Users/apple/.gemini/antigravity/scratch/arpit-portfolio
python3 -m http.server 8080
```
Then visit: `http://localhost:8080`

### Option 2: Node.js (npx serve)
```bash
npx serve /Users/apple/.gemini/antigravity/scratch/arpit-portfolio
```

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Create a repository named `Arpit-aka-appu.github.io` on GitHub.
2. Push the files in this directory to your repository.
3. Your portfolio will immediately be live at: `https://arpit-aka-appu.github.io`

### 2. Vercel / Netlify
1. Drag and drop the `arpit-portfolio` folder directly into [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
2. Enjoy instant SSL and ultra-fast global CDN delivery.
